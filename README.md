# ボウリングフォーム分析 (Web)

スマホのカメラで投球を撮影し、姿勢推定でフォームを分析して、文章と音声でフィードバックするブラウザアプリです。
インストール不要で、iPhone の Safari で開いて「ホーム画面に追加」して使います。

**https://dathenst.github.io/bowling-form/**

## 個人情報とデータの扱い

- **動画・分析結果・設定は、すべて使っている端末のブラウザ内(IndexedDB / localStorage)にだけ保存されます。** 運営側のサーバーはなく、このリポジトリや GitHub には何も送られません。
- 姿勢推定は端末内(ブラウザ)で動きます。映像は外部に送信されません。
- **AI の詳細分析(任意)を有効にしたときだけ**、投球の主要局面の画像(4枚)と計測値が、あなた自身の Google Gemini API キーで Google の API へ送信されます。キーはブラウザの localStorage にのみ保存されます。無料枠では入力が Google の製品改善に使われる場合があります。
- ブラウザのサイトデータを消すと、保存した動画や設定も消えます。残したい動画は、履歴の詳細から書き出してください。

## できること

- 姿勢推定(MediaPipe Pose Landmarker)でリアルタイムに骨格と指標(前傾・膝・肘・肩の傾き・腕の位置など)を表示
- 投球の動きを検知して、自動で録画の開始・停止(動き出しの約1秒前から保存)
- 投球直後に、文章と日本語音声でフィードバック。AI(Gemini)による詳細な講評(任意)
- **撮影位置**: 真横 / 真後ろ。**利用場所**: 自宅 / ボウリング場(レーン前の人だけを分析)
- ボウリング場向けの **設置ガイド**(補助線・水平器)と **キャリブレーション**、検知されないときの **診断表示**
- **お手本プリセット**: お手本にしたいボウラーの動画ファイルから、フォームの目標値を作成
- **直したい点(重点項目)**: 「ボールを背負う癖」「体からの離れ」などを指定して、毎回優先して指摘
- **直近の投球との比較**(改善/悪化と推移の傾向)、判定基準を肉眼ラベルから調整
- 履歴の詳細で、検出した骨格を録画に重ねて再生

## 使い方

1. iPhone の Safari で上の URL を開き、共有 → 「ホーム画面に追加」。
2. 「撮影」タブで「カメラを開始」(カメラの許可が必要)。三脚で固定し、全身が映るようにします。
3. 設定タブで、利き手・撮影位置・利用場所を選びます。AI を使う場合は、[Google AI Studio](https://aistudio.google.com/apikey) で無料の API キーを作って入力します。

横からの撮影は、アプローチに対して真横。後ろからの撮影は、レーンの延長線上でボウラーの真後ろに置きます。

## 注意

- フォームの「良い範囲」や検知のしきい値は、一般的な目安から置いた**初期値**で、十分な実測で検証されたものではありません。2D の姿勢推定なので、撮影角度やカメラ位置による誤差があります。「判定基準の調整」で、肉眼の判断に合わせて調整できます。
- 医療・競技指導の代わりにはなりません。
- 外部の読み込み: MediaPipe(jsDelivr / Google Cloud Storage)。

## 開発

ビルド不要の静的サイトです(素の ES modules)。

```bash
node test/sim.mjs                 # 検知・解析ロジックのテスト(合成した姿勢データ)
python -m http.server 8000        # PC のブラウザで確認(localhost ならカメラは HTTP でも可)
```

iPhone から LAN 内の PC に直接つなぐ場合は、カメラに HTTPS が必要です。`node serve.mjs` は mkcert で作った証明書を使う簡易 HTTPS サーバーです(証明書は `~/.bowlingform-certs`、リポジトリには置きません)。GitHub Pages で使う場合は不要です。

`main` への push で、テストを通したうえで GitHub Pages に自動デプロイされます。
